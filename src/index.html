Firewall do Windows
Permita apenas os endereços necessários para conectar outro dispositivo.
A regra vale só para o executável do motor (llama-server.exe ou o Python do Strata), a porta ativa e a faixa indicada, e continua no Windows depois que o servidor para. No Strata/PolyStrata, o executável é o python.exe instalado no sistema, compartilhado por qualquer programa Python: remova a regra quando parar de usar em Configurações > 07 · Firewall do Windows. O vLLM no Docker exige liberar a porta manualmente.

07 · FIREWALL DO WINDOWS
Regras criadas pelo launcher
As regras de entrada criadas pelo botão de firewall da tela Llama continuam no Windows depois que o servidor para. No Strata/PolyStrata elas liberam o python.exe do sistema, usado por qualquer programa Python. Remova-as quando não precisar mais do acesso pela rede. O Windows pede autorização de administrador só se houver regras para apagar; regras de outros programas não são tocadas.

    
08 · API DE CONTROLE
Controle pelo DepTriagem
Desligada
Permite que o DepTriagem (antigo DevTools) liste os modelos, inicie e pare o servidor principal, o revisor e o decisor e feche o launcher pela API local em http://127.0.0.1:8787/v1/control. Só aceita pedidos deste computador, com o token de controle (variável DEPTRIAGEM_LAUNCHER_TOKEN; o nome antigo DEVTOOLS_LAUNCHER_TOKEN ainda é aceito). Os serviços iniciados por ela escutam só em 127.0.0.1 e usam o perfil salvo de cada modelo.
Desligada: nenhuma porta aberta.
