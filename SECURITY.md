# Política de segurança

## Versões com suporte

Apenas a versão mais recente publicada recebe correções de segurança. Atualize para a versão mais recente antes de relatar um problema.

## Como relatar uma vulnerabilidade

Use o [relato privado de vulnerabilidade do GitHub](https://github.com/valmorbida4-eng/llama-desktop-launcher/security/advisories/new). Não publique vulnerabilidades em issues, discussões ou outros canais públicos. Não inclua senhas, tokens, chaves, dados pessoais ou outros segredos no relato. Se precisar compartilhar evidências, remova os segredos antes.

A equipe confirmará o recebimento e avaliará o relato assim que possível. Não há prazo garantido para resposta ou correção.

# Security Policy

## Supported versions

Only the latest published version receives security fixes. Please update to the latest version before reporting an issue.

## Reporting a vulnerability

Use [GitHub's private vulnerability reporting](https://github.com/valmorbida4-eng/llama-desktop-launcher/security/advisories/new). Do not disclose vulnerabilities in public issues, discussions, or other public channels. Do not include passwords, tokens, keys, personal data, or other secrets in a report. Remove secrets from any evidence before sharing it.

The team will acknowledge and assess reports as soon as possible. No response or fix timeline is guaranteed.
